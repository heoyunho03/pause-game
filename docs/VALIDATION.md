## 미실행·접근 차단
- Neon 앱 미연결: PAUSE DB 생성·SQL 적용·실제 Neon 연결과 두 실제 계정의 저장·복원 미실행.
- Google OAuth 웹 클라이언트 미설정. 콘솔 접속은 Site Unavailable 상태로 차단되어 허용 출처 등록·실제 로그인 미실행.
- Cloudflare Pages Production 환경변수는 초기 확인 시 비어 있었다. DATABASE_URL / GOOGLE_CLIENT_ID 미설정.
- GitHub Actions Secrets는 연결된 GitHub API에서 등록 기능이 제공되지 않는다. main 배포 job에서 실제 설정 여부를 확인한다.
- Android/iOS 실기기 검사는 수행하지 않았다. 모바일 결과는 Chromium 에뮬레이션이다.

최종 배포와 CI 결과가 확정되면 이 기록을 갱신한다.
