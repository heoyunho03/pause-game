# PAUSE v1.8 — 플레이 품질 1차 스케일업

기준 빌드: PAUSE v1.7 전체 12개 게임. v1.7 소스 ZIP의 파일들을 복원하여 로컬 분기에서 변경. 외부 GitHub/운영 사이트/Firebase 변경 없음.

## 실제 변경사항

1. **나이프 타이밍**: 기존 고정 ±0.24rad 각도 비교 대신 렌더링에 사용되는 칼 길이와 폭에 맞춘 2D 다각형(SAT) 충돌판정. 날아가는 동안 6ms 이하 간격으로 검사하여 중간 겹침 누락 방지. 스테이지당 꽂힌 칼과 요구 칼 합계 최대 11개로 제한해 원형 둘레 물리적 수용량을 고려. 편안하게/클래식/챌린지 난이도별 속도·목표 칼 수·기존 칼 수·점수 보정. 선셋 우드/딥 오션/미드나이트 비주얼 스킨 3종. 스킨은 규칙에 영향 없음. 기존 로컬 저장키 `knife-premium-v1` 유지, mode/skin 누락 기록은 클래식/선셋으로 읽음. 새로운 난이도별 최고 기록 키 `best-knife-{mode}`.
2. **스카이 롤**: 화면에 표시되는 공 반지름, 도로 빈 영역·장애물 폭에 근거해 X축 겹침 판정 조정. 편안하게/클래식/챌린지별 주행 속도 및 방해물 발생 확률. 난이도별 최고 기록 분리. 기존 `sky-roll-3d-v1`, `best-rolling3d` 복원 지원(기존 값은 클래식으로 조회).
3. **무한 달리기**: 최근접 차선만 보고 충돌하던 로직을 화면에 그린 기둥·장애물·게이트·구멍 폭과 캐릭터 폭의 연속 X 좌표 겹침으로 변경. 점프/슬라이드의 상하 회피 조건 유지. 편안하게/클래식/챌린지별 속도 및 장애물 생성 빈도. 난이도별 기록 분리, `runner-3d-v1`/`best-runner3d` 구형 기록 호환.
4. **플랫폼 일관성**: 기존 12종 홈 화면과 게임 공통 셸, 블루 `#335D9E`·선셋 `#D58D61` 브랜드, 로그인 없이 실행·로컬 저장 구조 유지.

## 미완료/다음 품질 단계

- 오프라인 HTML의 직접 `file://` 실행은 이 환경의 보안 정책 `ERR_BLOCKED_BY_ADMINISTRATOR` 때문에 확인 불가. HTML 소스 브라우저 주입 시 정상 동작 검증. 실제 로컬 Chrome/Edge 및 배포용 URL로 별도 테스트 필요.
- WebGL 실기기 GPU 렌더링, 모바일 중저가 성능, 장시간 플레이(발열·메모리), 키보드/스크린리더 접근성, 모든 게임의 승패·저장·난이도 분포 전체 회귀 테스트는 미완료.
- 칼 스킨은 3종 구현; **전체 12개 게임 스킨 시스템**은 아직 미구현. 실물 같은 3D 캐릭터·버스·방벽, 효과음/진동/파티클, 아트워크 일관성은 추후 제작.
- 트럭 탈출의 고난도 생성기 보강, 버스 및 방벽 그래픽 구현은 이전 사용자 피드백에 따라 우선 후속 작업.
- 조작 물리 판정은 렌더링의 근사 충돌체로 개선했으나 실제 모바일 기기·FPS 변동에서 수치 튜닝 필요.

## 배포 안내

정적 사이트 `index.html` 파일을 서빙하면 동작. 별도 데이터베이스나 서버 작업 필요 없음. 기존 Firebase/Google 로그인 동기화는 여전히 연결되지 않음. 파일은 로컬 테스트용이며 GitHub/Cloudflare 배포를 수행하지 않았음.
